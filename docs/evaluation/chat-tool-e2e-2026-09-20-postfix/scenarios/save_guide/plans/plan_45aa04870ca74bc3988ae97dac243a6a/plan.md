
# 桂林三日旅游攻略

## 一、行程总览

| 天数 | 主题 | 主要区域 | 强度 |
| --- | --- | --- | --- |
| 第 1 天 | 桂林市区山水初体验 | 象鼻山、两江四湖、东西巷 | 轻松 |
| 第 2 天 | 漓江精华 + 阳朔西街 | 漓江竹筏/游船、兴坪、西街 | 中等 |
| 第 3 天 | 阳朔田园与返程 | 遇龙河、十里画廊、返程 | 中等 |

**建议住宿**：第 1 晚住桂林市区（中心广场/两江四湖附近），第 2 晚住阳朔西街或遇龙河沿岸。

## 二、逐日安排

### 第 1 天：桂林市区

| 时间 | 安排 | 说明 |
| --- | --- | --- |
| 上午 | 抵达桂林，入住市区酒店 | 放行李、稍作休整 |
| 中午 | 正阳步行街 / 东西巷午餐 | 桂林米粉、啤酒鱼 |
| 下午 | 象鼻山公园 | 桂林城徽，1.5–2 小时 |
| 傍晚 | 两江四湖环湖步道 | 免费步行，看日月双塔 |
| 晚上 | 东西巷 + 逍遥楼夜景 | 晚餐、逛街 |

**可选加项**：两江四湖夜游船（需提前订票，约 1.5 小时）。

### 第 2 天：漓江精华 → 阳朔

| 时间 | 安排 | 说明 |
| --- | --- | --- |
| 早上 | 桂林出发前往磨盘山/竹江码头 | 车程约 40 分钟 |
| 上午–下午 | 漓江精华段游船（约 4 小时） | 途经九马画山、黄布倒影，终点阳朔 |
| 下午 | 抵达阳朔，入住 | 西街或遇龙河附近 |
| 傍晚 | 兴坪古镇 + 20 元人民币背景取景地 | 可顺路安排 |
| 晚上 | 阳朔西街 | 晚餐、酒吧街、逛街 |

**替代方案**：若想更灵活，可改为「杨堤—兴坪」竹筏漂流（约 1.5–2 小时），再自行前往阳朔。

### 第 3 天：阳朔田园 + 返程

| 时间 | 安排 | 说明 |
| --- | --- | --- |
| 上午 | 遇龙河竹筏漂流 | 约 1.5–2 小时，田园风光最佳 |
| 中午 | 旧县 / 兴坪农家菜 | 午餐 |
| 下午 | 十里画廊骑行 | 租电动车或自行车，约 2–3 小时 |
| 傍晚 | 返回桂林或直接返程 | 阳朔有高铁站（阳朔站） |

---

## 三、交通建议

- **桂林 ↔ 阳朔**：高铁约 30 分钟；大巴约 1.5 小时；漓江游船约 4 小时（本身即景点）。
- **阳朔内部**：租电动车最方便（约 50–80 元/天），也可打车或包车。
- **市区**：公交、打车均可，景点间距离不远。

## 六、实用提示

1. **最佳季节**：4–10 月，其中 4–6 月雨季水量大、山水最绿，但需备雨具。
2. **漓江游船**：旺季需提前 1–2 天订票，建议选上午班次。
3. **防晒防蚊**：竹筏、骑行户外时间长，注意防晒和驱蚊。
4. **天气影响**：遇暴雨漓江可能停航，出发前查天气和船班通知。
5. **行程弹性**：第 2、3 天可根据体力互换，遇龙河与十里画廊也可合并为一天。
