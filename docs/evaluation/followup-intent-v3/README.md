## 冻结与重现

`manifest.json` 固定契约、案例、评分器、评分器测试和生成提示词的 SHA-256。先冻结，后开发集，最后留出集；本轮未利用开发集调优。冻结文件不能原地修订后覆盖旧结果。

在仓库根目录，配置模型环境后执行（会产生实际费用，输出目录必须不存在）：

```powershell
python -X utf8 backend/scripts/followup_intent_v3.py --execute --split dev --out docs/evaluation/followup-intent-v3/dev-new
python -X utf8 backend/scripts/followup_intent_v3.py --execute --split holdout --out docs/evaluation/followup-intent-v3/holdout-new
```

`--resume` 仅离线读取已有调用回执；不会补发未发送的请求或重试状态不明的调用。`results.json`、`cases.snapshot.json`、`prompt.txt` 与逐次 `*-call.json` 保存输入、预测、原始回执、用量和评分。缺失、错误、截断不会从分母移除。reason 不参与匹配，目标数组顺序无关。

## 评测边界

- 这是独立的契约分类探针，没有接入生产决策或执行任何业务写入；不能据此宣布线上意图层达到相同准确率。旧 v1/v2 结果和评分协议未改。
- 案例由开发者编写，按 family 字段隔离，不是独立人工盲审。family 不同也不等于语义完全独立；留出集如今已被查看，后续调优应使用新的外部评审集。
- 覆盖旅游、健身、学习、财务、烘焙等场景，包括正反例、多目标、澄清、提醒、文档与复盘发起方式。单次合成测试不能保证生产可靠性；零误触仅指这些案例。
- 跨目标污染指标仅检测评分器定义的可识别错误，不能证明任意语义污染为零。
- 总用量：未缓存输入 15,049，缓存读取 116,224，输出 3,859，推理 0；未核验计费单价，费用未知。
