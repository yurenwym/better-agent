
# 桂林三日旅游攻略

## 一、行程总览

| 天数 | 主题 | 主要区域 | 核心体验 |
|---|---|---|---|
| 第 1 天 | 桂林市区山水初识 | 象鼻山—两江四湖—正阳步行街 | 城徽打卡、夜游环城水系 |
| 第 2 天 | 漓江精华 + 阳朔西街 | 磨盘山码头—兴坪—阳朔 | 漓江竹筏/游船、20 元人民币背景地 |
| 第 3 天 | 阳朔田园与返程 | 遇龙河—十里画廊—返桂林 | 竹筏漂流、骑行田园、返程 |

**节奏说明**：三天属于紧凑但不赶的经典组合，第 2 天路程最长，建议早出发；第 3 天下午留出返程缓冲。

## 二、逐日安排

### 第 1 天：桂林市区

| 时间 | 安排 | 说明 |
|---|---|---|
| 上午 | 抵达 + 入住 | 建议住市中心（十字街、正阳步行街一带），方便步行 |
| 中午 | 桂林米粉 | 本地吃法是干拌卤菜粉，汤另配 |
| 14:00–16:30 | 象鼻山 | 桂林城徽，1 号门进、2 号门出较顺；江边可看日月双塔 |
| 17:00–18:30 | 靖江王府 / 东西巷 | 明代藩王府遗址，东西巷为历史街区，适合慢逛 |
| 19:30–21:00 | 两江四湖夜游 | 环城水系夜景，日月双塔、玻璃桥是亮点；也可沿湖步行免费看 |
| 21:00 后 | 正阳步行街 | 小吃与夜市 |

**当日提示**：象鼻山与两江四湖距离近，步行或打车 10 分钟内可达。

### 第 2 天：漓江精华 + 阳朔

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:00–07:30 | 出发前往码头 | 磨盘山码头（游船）或杨堤码头（竹筏），车程约 40–60 分钟 |
| 09:00–13:00 | 漓江精华段 | 杨堤—兴坪为最精华段；游船约 4 小时，竹筏约 1.5–2 小时 |
| 13:00–14:00 | 兴坪古镇午餐 | 兴坪老寨山、20 元人民币背景观景点 |
| 15:00–16:30 | 前往阳朔 + 入住 | 兴坪到阳朔约 40 分钟车程 |
| 17:00–18:30 | 西街 | 阳朔最热闹的步行街，傍晚开始有人气 |
| 19:30–21:00 | 《印象·刘三姐》或遇龙河夜游 | 山水实景演出，需提前订票 |

**当日提示**：漓江游船与竹筏是两种不同体验，游船平稳适合看全景，竹筏更贴近水面但受水位影响可能停运，出行前确认当日通航情况。

### 第 3 天：阳朔田园 + 返程

| 时间 | 安排 | 说明 |
|---|---|---|
| 08:00–10:30 | 遇龙河竹筏 | 比漓江更安静，两岸田园风光；建议选上半段 |
| 10:30–12:30 | 十里画廊骑行 | 租电动车或自行车，途经月亮山、大榕树 |
| 12:30–14:00 | 农家午餐 | 啤酒鱼、田螺酿为阳朔特色 |
| 14:00–16:00 | 返桂林 | 阳朔到桂林约 1.5 小时（大巴/高铁） |
| 16:00 后 | 返程 | 视航班/车次安排 |

## 三、交通建议

- **市区内**：打车或公交即可，景点集中，单程多在 10–20 元。
- **桂林 → 阳朔**：高铁约 30 分钟（阳朔站离县城约 40 分钟车程）；大巴约 1.5 小时直达汽车站。
- **阳朔内**：租电动车最方便，约 50–80 元/天；也可包车。
- **漓江段**：游船票与竹筏票建议提前 1–2 天预订，旺季更早。

## 七、注意事项

1. **天气**：4–6 月为雨季，漓江水位上涨可能影响竹筏；7–8 月炎热多雨，注意防晒防蚊。
2. **旺季**：五一、国庆、暑假人多，船票、住宿需提前预订。
3. **竹筏安全**：穿救生衣，贵重物品做好防水。
4. **行程弹性**：第 2 天如遇漓江停航，可改为阳朔周边（银子岩、世外桃源）替代。
5. **返程预留**：第 3 天返程建议留出至少 3 小时缓冲。
