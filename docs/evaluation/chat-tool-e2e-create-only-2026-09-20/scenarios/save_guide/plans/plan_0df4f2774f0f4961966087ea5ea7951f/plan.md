
# 桂林三日旅游攻略

## 一、行程总览

| 天数 | 主题 | 主要区域 | 核心体验 |
|---|---|---|---|
| 第 1 天 | 桂林市区山水初识 | 象鼻山—两江四湖—正阳步行街 | 城徽打卡、夜景环湖 |
| 第 2 天 | 漓江精华 + 阳朔西街 | 磨盘山码头—兴坪—阳朔 | 漓江竹筏/游船、20 元人民币背景地 |
| 第 3 天 | 阳朔田园与返程 | 遇龙河—十里画廊—返桂林 | 竹筏漂流、骑行田园 |

**节奏说明**：三天属于紧凑但不赶的经典组合，第 2 天路程较长，建议早出发；第 3 天下午留出返程缓冲。

## 二、逐日安排

### 第 1 天：桂林市区

| 时间 | 安排 | 说明 |
|---|---|---|
| 上午 | 抵达桂林，入住市区（推荐中心广场/正阳步行街附近） | 便于步行和夜游 |
| 中午 | 桂林米粉（卤菜粉） | 本地早餐/午餐主食，人均 10–20 元 |
| 下午 | 象鼻山公园 | 桂林城徽，1–1.5 小时可逛完 |
| 傍晚 | 两江四湖环湖步行或乘船 | 步行免费，游船约 1.5 小时 |
| 晚上 | 正阳步行街、东西巷 | 小吃与夜景 |

**当日提示**：象鼻山公园需提前在官方渠道预约门票；两江四湖夜游船票建议提前一天预订。

### 第 2 天：漓江精华段 + 阳朔

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:00 前 | 出发前往磨盘山码头（或竹江码头） | 市区车程约 40–60 分钟 |
| 上午 | 漓江游船（磨盘山—阳朔，约 4 小时） | 途经九马画山、黄布倒影 |
| 中午 | 船上简餐或到阳朔后用餐 | 船上餐食一般，可自备干粮 |
| 下午 | 兴坪古镇、20 元人民币背景地 | 若乘船直达阳朔，可另安排兴坪半日 |
| 傍晚 | 入住阳朔，逛西街 | 西街夜间热闹，注意财物 |
| 晚上 | 《印象·刘三姐》实景演出（可选） | 需提前订票，雨天可能停演 |

**当日提示**：漓江游船分“全程游船”和“竹筏精华段”两种玩法。竹筏通常只走杨堤—兴坪段，时间更短、更灵活，但受水位和天气影响较大，出发前务必确认当日是否开航。

### 第 3 天：遇龙河 + 十里画廊 + 返程

| 时间 | 安排 | 说明 |
|---|---|---|
| 上午 | 遇龙河竹筏漂流（金龙桥—旧县段较经典） | 约 1.5–2 小时，比漓江更安静 |
| 中午 | 阳朔县城用餐 | 啤酒鱼为当地特色 |
| 下午 | 十里画廊骑行 | 租电动车或自行车，约 2–3 小时 |
| 傍晚 | 返回桂林市区或直接前往机场/高铁站 | 阳朔到桂林约 1.5 小时 |

**当日提示**：返程当天不要把行程排太满，遇龙河漂流排队时间在旺季可能较长。

## 三、交通建议

- **桂林市区**：公交、打车都方便，景点集中，步行即可覆盖两江四湖一带。
- **桂林 → 阳朔**：可选漓江游船（观景最佳）、高铁（桂林站/桂林北站到阳朔站约 30 分钟）、大巴（约 1.5 小时）。
- **阳朔县内**：租电动车最灵活，一般 50–80 元/天；骑行十里画廊建议选电动车。
- **注意**：阳朔高铁站离县城约 30 公里，需另乘接驳车或打车。

## 七、行前准备与注意事项

1. **天气**：桂林 4–6 月多雨，漓江水位影响游船与竹筏，出行前查当日开航公告。
2. **防晒防蚊**：夏季紫外线强，江边蚊虫多。
3. **门票预约**：象鼻山、漓江游船、印象刘三姐建议提前 1–2 天预订。
4. **现金与支付**：景区小摊可能只收现金或扫码，备少量现金。
5. **旺季提醒**：五一、国庆、暑假人流大，住宿和船票需提前更久预订。
6. **体力安排**：第 2 天行程最满，前一天早点休息。

## 八、可调整方案

- **想更轻松**：把漓江游船换成杨堤—兴坪竹筏，第 2 天下午直接到阳朔休息。
- **想加龙脊梯田**：需额外 1 天，建议改为四日行程，龙脊往返市区约 2.5 小时车程。
- **亲子出行**：减少骑行，增加遇龙河竹筏和西街休闲时间。
