
# 桂林三日旅游攻略

## 一、行程总览

| 天数 | 主题 | 主要区域 | 强度 |
|---|---|---|---|
| 第 1 天 | 桂林市区山水初体验 | 象鼻山、两江四湖、东西巷 | 轻松 |
| 第 2 天 | 漓江精华 + 阳朔西街 | 漓江竹筏/游船、兴坪、西街 | 中等 |
| 第 3 天 | 阳朔田园与返程 | 遇龙河、十里画廊、返程 | 中等 |

**建议住宿**：第 1 晚住桂林市区（中心广场/正阳步行街附近），第 2 晚住阳朔西街周边，方便次日行程。

---

## 二、逐日安排

### 第 1 天：桂林市区

| 时间 | 安排 | 说明 |
|---|---|---|
| 上午 | 抵达桂林，入住市区酒店 | 若中午前到，可先寄存行李 |
| 中午 | 正阳步行街 / 东西巷用餐 | 桂林米粉、啤酒鱼 |
| 下午 | 象鼻山公园 | 桂林城徽，1.5–2 小时 |
| 傍晚 | 两江四湖·日月双塔 | 日落前后光线最好 |
| 晚上 | 夜游两江四湖（可选） | 乘船约 1.5 小时，需提前订票 |

**当日要点**：市区景点集中，步行 + 打车即可，不必包车。

### 第 2 天：漓江精华段 → 阳朔

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:00–08:00 | 出发前往磨盘山码头或竹筏起点 | 视所选方式而定 |
| 上午 | 漓江精华段（杨堤—兴坪） | 游船约 4 小时；竹筏约 1.5–2 小时 |
| 中午 | 兴坪古镇用餐 | 兴坪老街小吃 |
| 下午 | 20 元人民币背景取景地、老寨山（体力好可选） | 老寨山往返约 1.5 小时，台阶较陡 |
| 傍晚 | 前往阳朔，入住西街附近 | 车程约 40 分钟 |
| 晚上 | 阳朔西街 | 餐饮、酒吧街，注意财物 |

**当日要点**：漓江游船与竹筏是两种不同体验，游船舒适、竹筏更贴近水面；旺季务必提前 1–2 天订票。

### 第 3 天：阳朔田园 → 返程

| 时间 | 安排 | 说明 |
|---|---|---|
| 上午 | 遇龙河竹筏漂流 | 推荐上半段，约 1.5–2 小时 |
| 中午 | 旧县 / 兴坪一带农家菜 | — |
| 下午 | 十里画廊骑行 | 租电动车或自行车，约 2–3 小时 |
| 傍晚 | 返回桂林或直接前往高铁站/机场 | 阳朔有直达桂林两江机场的大巴 |

**当日要点**：返程交通要预留缓冲，阳朔到桂林市区约 1.5 小时，到机场约 1.5–2 小时。

## 四、实用提示

- **最佳季节**：4–10 月，其中 4–6 月雨多但山水最润；7–8 月炎热多雨，注意防晒防蚊。
- **天气影响**：漓江水位过高或过低时游船/竹筏可能停运，出发前查当日通知。
- **订票**：漓江游船、遇龙河竹筏、两江四湖夜游建议提前在线预订。
- **装备**：防滑鞋、雨具、防晒、驱蚊液；竹筏会溅水，可备防水袋。
- **避坑**：西街周边拉客的“低价一日游”谨慎选择；竹筏务必走正规码头。

---

## 五、可调整项

- 若只有 2 天：删去第 3 天，第 2 天下午直接从兴坪返程。
- 若偏爱徒步：可把第 3 天十里画廊换成阳朔—兴坪徒步段。
- 若带老人小孩：第 2 天选游船而非竹筏，第 3 天减少骑行时长。
