# T02：网关和工具错误适配

状态：完成。实际完成范围见 [开发记录](implementation-notes.md)。

## 前置

T01。 规范：[C01](C01-Error-Outcome契约.md)、[C02](C02-Event-Trace契约.md)。顺序见 [README](README.md)。

## 要做

1. 在最接近边界的位置为 GatewayError、ToolResult、ToolRejected、ToolReconciliationRequired 和实际身份/来源错误增加集中转换。
2. 先处理更具体的对账子类，再处理拒绝父类；网关保留 kind/attempts 根因，不把未知供应商错误归为非法模型动作。
3. 区分工具验证前拒绝、明确成功、明确未执行失败和发送后响应丢失；写操作 unknown 沿用对账服务。
4. 保证错误属性不会自动启动新重试；发送/重试前沿用身份、来源及预算检查。
5. 正常可纠正工具失败仍可返回模型处理；不要把 ToolResult.ok=false 全部抛成终止异常。

## 交付

小型边界适配函数及针对网关/工具的回归用例；原异常类可保留。

## 验收

覆盖认证、预算、超时、限流、工具参数、工具拒绝、对账、未知异常；写工具响应丢失只执行一次；日志/公开消息不泄密。

## 禁止

不通过字符串匹配异常推断类别；不新增重试器；不削弱审批或来源检查。
