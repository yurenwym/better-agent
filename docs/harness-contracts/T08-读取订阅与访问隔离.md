# T08：读取订阅与访问隔离

状态：已实现并验证。实际完成范围见 [开发记录](implementation-notes.md)。

## 前置

T07。 规范：[C01](C01-Error-Outcome契约.md)、[C02](C02-Event-Trace契约.md)。顺序见 [README](README.md)。

## 要做

1. 让现有读取、SSE 和投影入口消费适配后的记录，同时输出旧客户端需要的形状。
2. 逐项保留 plan.document_ready 的 source_message_id、既有 type 和增量游标含义。
3. 测试断线重连、重复投递与历史流混合版本；按 event_id 去重，不要求跨流全局顺序。
4. 按现有权限入口校验 owner 和资源关联，涵盖 outcome/trace/snapshot 引用；公开投影脱敏，内部恢复数据不被破坏。
5. 未知事件类型可读或可跳过，不能中断整条历史读取；转录 canonical/hash 不变化。

## 交付

现有读取/订阅适配与后端、必要前端兼容测试；不新建展示页面。

## 验收

旧客户端契约用例通过；A 用户不能读取 B 的 trace 或快照；密钥及原始异常不出现在公开 payload；重连不会触发业务重复执行。

## 禁止

不要求前端重构；不因字段带 UUID 就跳过权限；不重算历史转录或快照摘要。
