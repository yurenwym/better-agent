## 前置

T06。 规范：[C01](C01-Error-Outcome契约.md)、[C02](C02-Event-Trace契约.md)。顺序见 [README](README.md)。

## 要做

1. 按顺序接入对话入口 → 模型/工具调用 → 等待与恢复 → 研究/专家移交 → 目标步骤。
2. 复用 HarnessExecutionContext 的工厂和持久化校验；禁止从模型参数接受 owner/trace。
3. 为操作开始、结束、等待、恢复和实际重试记录最小必要语义事件；高频文本 delta 保持现有传输路径。
4. 审批决定与恢复建立 causation 引用；恢复 trace 不变、新 span；重复审批请求不重复执行操作。
5. 为已存在的模型 retry 记录实际 attempt，禁止为了补 trace 增加调用次数；深度研究仅接通工具边界与任务引用。
6. 取消/超时后的最终结果、unknown 对账和迟到响应有一致收尾，不产生两个互斥最终状态。

## 交付

生产者接入与主链路 trace 回归；按现有测试位置新增少量聚焦用例。

## 验收

仅凭持久化事件可定位一次对话的模型/工具调用、审批恢复和移交目标；跨 owner 引用被拒绝；根身份未重新生成；每次实际尝试有一致结果。

## 禁止

不改研究算法；不建全局 trace 单例；不将补日志异常吞掉后继续执行缺失关键审计的写操作。
