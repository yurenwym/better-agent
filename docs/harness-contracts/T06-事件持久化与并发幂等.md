# T06：事件持久化与并发幂等

状态：已实现并验证。实际完成范围见 [开发记录](implementation-notes.md)。

## 前置

T05。 规范：[C01](C01-Error-Outcome契约.md)、[C02](C02-Event-Trace契约.md)。顺序见 [README](README.md)。

## 要做

1. 在现有 events/thread_events 添加最少必要元数据及索引/约束，迁移兼容已有数据和仓库支持的数据库。
2. 确定元数据单一事实来源；更新 store 的 append/list，使旧调用签名可逐步迁移，主链路新记录必须满足 C02。
3. 修复流内序号并发分配；使用数据库能力保证同一 stream 唯一递增。
4. 实现重复 event_id/幂等键处理：同内容复用，异内容冲突；冲突比较排除数据库派生 seq 等非业务字段。
5. 关键事件支持复用调用方事务；提交后才发布/投影；检查外部发送意图与未知副作用的崩溃窗口。

## 交付

最小数据库迁移、store 改动与 tests/integration/test_event_envelope_postgres.py。

## 验收

真实 PostgreSQL 并发 append 不重复 seq；重复写不重复事件；异内容冲突；事务回滚无事件；历史行升级可读；进程重建后游标可继续。

## 禁止

不以单线程 SQLite 用例替代 PostgreSQL 并发验证；不裸用 MAX(seq)+1；不声称事件幂等保证工具 exactly-once。
