# T05：事件契约与旧数据适配

状态：完成。实际完成范围见 [开发记录](implementation-notes.md)。

## 前置

T04。 规范：[C01](C01-Error-Outcome契约.md)、[C02](C02-Event-Trace契约.md)。顺序见 [README](README.md)。

## 要做

1. 按 C02 实现 EventEnvelope 与可信上下文构造入口；结果字段复用 C01 编解码。
2. 为现有 Event、ThreadEvent 定义投影映射及新旧版本辨识；旧 schema_version 不直接解释为外壳版本。
3. 明确新事件必填 context 与历史缺失 context 的只读类型边界。
4. 定义 operation_id/attempt、审批恢复、因果引用及 snapshot_refs 的确切映射，使用已有 ID，避免重复造概念。
5. 保留 domain type 和 payload；为当前主链路关键事件建立必要字段校验，不实现插件注册系统。

## 交付

event_envelope.py、旧记录适配及 tests/test_event_envelope.py。

## 验收

新旧记录可区分；旧 event_id/seq/type 不变；上下文冲突拒绝；未知版本不能驱动执行；结果字段可正确往返。

## 禁止

不改 TranscriptEvent.canonical；不补造历史 trace；不先建第二份事件表。
