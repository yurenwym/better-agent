## 二、交互路径用例（人工/自动化均可）

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| I1 | 定时任务删除确认 | 定时研究页 → 点「删除」 | 先弹「删除定时任务？」确认框；取消则不删；确认后删除且成功可见 |
| I2 | 通知渠道删除确认 | 定时研究页 → 通知渠道「删除」 | 同上，独立确认框 |
| I3 | 经历摘要删除确认 | 记忆页 → 最近经历「删除经历」 | 弹「删除经历摘要？」确认框；成功/失败均有可见反馈；失败后对话框关闭且错误可见（与 I1 行为一致） |
| I4 | 删除失败可见 | （自动化 SchedulesSafety）mock 删除失败 | 页面出现 role=alert 错误、删除 API 恰好调用一次、对话框关闭 |
| I5 | 审批失败可见 | （自动化 ApprovalFeedback）mock 审批接口 500 | 卡片内出现错误提示，按钮恢复可点，可重试成功 |
| I6 | 研究取消/重试失败可见 | 断网或 mock 失败时点取消/重试 | 出现中文错误提示（不再静默） |
| I7 | 真人模式失败可见 | （自动化 ShellResilience）mock setHumanMode 失败 | 顶部弹出 error toast；重试成功后勾选态同步 |
| I8 | 后端未连接提示 | （自动化 ShellResilience）bootstrap 失败 | 顶栏出现红色「后端未连接，操作可能不可用」标记 |
| I9 | 防双击 | 计划页连点「批准计划」 | busy 期间按钮禁用，仅触发一次；完成后恢复 |
| I10 | 加载不闪空态 | （自动化 ConsoleStates）Skills 页慢加载 | 加载期显示「加载中…」而不是「暂无 Skill」；Memory/Research/Schedules/Usage/Evaluation 同规则 |
| I11 | 流式反馈 | 对话页发起一轮流式回答 | 生成期间内容尾部有主色光标闪烁、消息行 aria-busy；完成后两者消失 |
| I12 | 自动滚动 | 长对话中跟随流式输出；手动上滚回看 | 距底 <120px 时自动跟随；用户回看时不被强行拉回 |
| I13 | AskCard 焦点 | 触发澄清问题卡 | 卡片出现后焦点落入卡内第一个可交互元素 |
| I14 | 技能面板可逃逸 | 打开输入框技能面板 | 按 Esc 或点击面板外部可关闭；面板内点击不关闭 |
| I15 | 来源加载失败可区分 | mock 来源接口失败 | 面板显示「来源暂时无法加载」而不是静默消失 |

## 三、回归红线（每批次闸门）

1. `npx vitest run` 全绿，且 **1ec94c6 基线的 213 个存量用例文件零修改**（`git diff 1ec94c6..HEAD -- frontend/src/__tests__/` 只允许新增文件）。
2. `git diff 1ec94c6..HEAD` 不含 `backend/**`、`frontend/src/api.ts`、`frontend/src/types.ts`、`frontend/e2e/**`。
3. `npm run build` 通过。
