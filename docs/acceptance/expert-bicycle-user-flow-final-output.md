# 7天骑车计划（保守入门版）

**适用前提（保守假设）**：你未提供骑行基础、车辆类型、路况、健康状况和每日可用时间。因此本计划默认：新手或久未骑行、平路、天气适宜、无医嘱限制。若实际情况不同，请按文末“调整规则”修改。

**核心参数**
- 强度：轻松，全程能边骑边正常说话。
- 每日骑行总时长上限：**30分钟**（含热身和放松）。
- 7天内安排 **2天完全休息/非骑行恢复**（第3天、第5天），共骑行5天。
- 不安排快骑、冲刺、间歇、爬坡冲刺或长距离。
- 休息日是计划的组成部分，不是“失败”，不补练。
- 本周只允许减量调整，不安排加量。

---

## 第1天 — 适应与车辆检查
- 任务：检查刹车、胎压、座垫高度；平路慢速骑行。
- 时长：热身5分钟（慢速、轻齿比）→ 主骑15分钟（轻松）→ 放松5分钟（慢速 + 拉伸小腿与大腿前侧）。**总计25分钟。**
- 强度：轻松，能完整说句子。
- 完成标准：完成25分钟；无疼痛；能说出车辆至少一项需调整处。

## 第2天 — 轻松骑行
- 任务：平路轻松骑，保持均匀踏频，不追求速度。
- 时长：热身5分钟 → 主骑20分钟 → 放松5分钟。**总计30分钟。**
- 强度：轻松。
- 完成标准：完成30分钟；结束后呼吸可在2分钟内恢复平稳。

## 第3天 — 完全休息 / 非骑行恢复
- 任务：不骑车。可散步10–15分钟或做温和拉伸。
- 时长：0分钟骑行；恢复活动≤15分钟。
- 完成标准：无骑行；睡眠与腿部无明显酸痛加重。

## 第4天 — 轻松骑行
- 任务：平路轻松骑，注意坐姿与手部放松。
- 时长：热身5分钟 → 主骑20分钟 → 放松5分钟。**总计30分钟。**
- 强度：轻松。
- 完成标准：完成30分钟；无膝痛、腰痛、手麻。

## 第5天 — 完全休息 / 非骑行恢复
- 任务：不骑车。可做温和拉伸或散步。
- 时长：0分钟骑行；恢复活动≤15分钟。
- 完成标准：无骑行；疲劳感下降。

## 第6天 — 轻松骑行
- 任务：平路轻松骑，可在舒适范围内保持稳定踏频。
- 时长：热身5分钟 → 主骑20分钟 → 放松5分钟。**总计30分钟。**
- 强度：轻松，不进入喘不过气的状态。
- 完成标准：完成30分钟；全程可对话。

## 第7天 — 轻松骑行 + 一周回顾
- 任务：平路轻松骑；结束后记录本周感受（疲劳、疼痛、睡眠）。
- 时长：热身5分钟 → 主骑20分钟 → 放松5分钟。**总计30分钟。**
- 强度：轻松。
- 完成标准：完成30分钟；写下一周总结。

---

## 通用规则
- 每次骑行前热身5分钟、后放松5分钟，已计入每日30分钟上限。
- 出现疼痛、头晕、胸闷、异常气短 → 立即停止，必要时就医。
- 天气差或身体不适 → 当天改为休息日，不补练。
- 本周总骑行天数：5天；完全休息/恢复：2天（第3天、第5天）。
- 若第1天就明显吃力，可将主骑缩短至10分钟，仍按轻松强度完成。

## 调整规则（按实际情况替换假设）
- 若为共享单车/通勤车：以时间与舒适度为准，不追求速度与踏频。
- 若为室内骑行台：同样执行时长与强度，注意通风与补水。
- 若有坡路：改为低齿比慢速上坡或下车推行，不安排爬坡冲刺。
- 若有膝、腰、心血管等医嘱限制：先咨询医生，再按医嘱调整或暂停。

## 可选定制（最多两个关键问题）
1. 你的骑行基础如何（从未骑/偶尔骑/经常骑）？
2. 是否有医生限制或伤病（膝、腰、心脑血管等）？
