## 真实失败与限制

原始批次都保留在 `prior-runs/`：初版有文字提问不调用 ask、一次模型超时；第二轮通用计划被不必要的澄清阻断；第三轮质量通过但延迟超门槛。之后补强通用计划假设规则、移除重复保存工具，并在当前时间窗口完整重跑双方，未删除失败样本。第 2 轮 Windows 报告替换失败时，从已落盘临时结果恢复第 65 例，没有重发。

70 个案例是作者整理的合成材料，46 DEV、24 HOLDOUT；HOLDOUT 冻结值未修改。作者参与编写，因此不宣称独立盲测；提示词改动依据 DEV 轨迹。最终仍有 6 个未命中，PASS 表示满足相对门禁，不表示全部意图都正确。
