# Agent 可靠性与用户体验优化方案

## 决策

用户要求三名子 Agent 独立研究、投票后开发。主 Agent 汇总，不代替子 Agent 投票。

| 子 Agent | 负责视角 | V1 投票 | 理由 |
| --- | --- | --- | --- |
| budget_dialogue | 费用、期限、Ask 续接 | 赞成 | 人工等待不扣执行时间，重试不清零预算，独立操作有持久化根预算 |
| execution_review | 行动、复盘、恢复 | 赞成 | 先保全反馈和摘要，提案失败不毁掉复盘，延期不重复计时 |
| experience_routing | 用户体验、路由、记忆边界 | 赞成 | 普通操作减少自动专家等待，保持偏好授权与证据边界 |

结果：3/3 赞成，无未解决的安全阻断。通过后开始开发。

## 实施契约

1. 编译、复盘、调整、周期总结具有稳定操作身份与持久化根预算，重启/自动重试不重置；子调用共享预算。生产 PostgreSQL 无有效预算时在网络前拒绝。
2. Ask 的持久化人工等待区间不计入执行期限；不重置费用或次数，不复活进入等待前已过期的预算；并发答案只续接一次。
3. 每日复盘摘要独立保存。调整有 NOT_NEEDED/PENDING/RUNNING/COMPLETED/NO_CHANGE/FAILED 阶段，失败可重试而无需重新总结。没有有效调整是正常结果，不强迫模型制造改变。
4. 延期仅继承已做/待做内容、产出和来源，不复制历史实际用时与难度。源日、目标日及替换行动统一刷新复盘证据；运行中/已完成快照只标过期，不覆盖。
5. Worker 临时错误有限退避，租约丢失停止当前调用，关闭有界，暴露运行/故障状态。
6. planner/reflector 用途与输入输出上限一致；复盘结构修复也保持短输出上限。
7. 普通编译/复盘默认单模型，主动专家协作入口保留；不增加推测型记忆权限。明确偏好按授权范围采用，习惯推断仍需重复证据与确认，支持撤回。

## 验收与边界

先离线故障注入及 PostgreSQL 并发测试，再做浏览器测试与有预算的 DeepSeek 小额验证。不让普通回归读取本机真实密钥。密钥仅保存在 Windows 用户环境变量，不记录在本方案、代码、测试输出或日志中。

不会把历史验收 PASS 当作当前全流程通过。无新证据不晋升进化候选；工程故障不变成用户习惯。暂不新增队列服务、任意自然语言习惯提炼或复杂度分类模型。
