状态：已完成（用户明确授权；首轮 legacy 70/70 完成，当前窗口复测 70/70 完成；原始报告保留在 outputs/agent-loop-live 与 outputs/agent-loop-live-v4）

## 目标

在 `legacy` 模式下用受控真实模型跑 T00 评测集，留下可对比的旧路径基线。

## 要做

1. 沿用现有 control store、可信 owner、独立评估预算、固定 profile/价格/bundle。
2. 启动前打印预计调用数和预算，按既有评估启动方式**显式授权**后再跑。
3. 输出 `docs/acceptance/agent-loop-m1/baseline-legacy.json` 与 `.md`：逐案例结果、按类别准确率、误触发、调用数、token、成本来源、首字延迟。
4. 记录代码版本、dirty、suite digest、模型、价格快照。未知成本标 `unknown`，不按零计。

## 验收

- 报告覆盖 T00 全部计划案例；无效样本未从分母消失。
- `COST_MODE`、命令、退出码、时间写入 `logs/`。
- 未获授权时任务标 `BLOCKED`，不得改用 mock 冒充基线。

## 禁止

- 不自动发起付费运行。
- 不改业务路由或提示词。
- 不用 mock 延迟或 mock 质量当作旧路径基线。
