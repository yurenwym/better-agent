# T05 抽出移交收尾共用函数

状态：已完成（既有 worker/PG 移交 45 passed，PG fencing 4 passed，独立前置检查 5 passed）  
依赖：无（可与 T02–T04 并行）  
阻塞：T06、T07

## 目标

把 `ManagedTurnWorker.run_once` 里 `start_research` / `start_expert` 的前置检查与落库收尾抽成可复用函数，旧路径改为调用它们。行为字节级一致，便于后续工具执行体复用，避免两套收尾。

## 要做

1. 从 `conversation.py` 约 2183–2246 行抽出例如：
   - `handoff_start_research(turn, topic, scope, *, connection)`
   - `handoff_start_expert(turn, objective, roles, *, history, plan_context, connection)`
2. 前置检查一并抽出：`context_incomplete`、`goal_action_id` 禁专家、研究服务是否配置、可见正文不得与移交同现。
3. 事务边界不变：任务创建、`turns` 状态、`turn_jobs` 完成、事件写入在同一事务。
4. 幂等：研究按 `source_turn_id`；专家按 `conversation-expert:{turn_id}`。
5. 旧 `run_once` 分支改为调用抽出函数。既有研究/专家回合测试不改断言。

## 改动范围

- `backend/app/conversation.py`
- 可选新建 `backend/app/conversation_handoff.py`（仅当文件继续膨胀时）

## 验收

- 现有 `start_research` / `start_expert` 集成测试通过。
- 抽出函数可被独立单测：冲突、缺配置、带可见正文时的拒绝。
